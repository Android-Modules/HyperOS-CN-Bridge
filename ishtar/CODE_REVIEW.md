# 3.3.1 生产版代码复核

复核范围：独立作用域、配置保存与启动事务、补装应用恢复、相册适配、QESDK 文本修复、WebUI 和两机型发布工作流。真机证据与验证边界见 [VALIDATION.md](VALIDATION.md)。

- 配套 Provider 仅允许 UID 0 调用；配置限制为固定功能 ID、有限长度、受限版本字符串，不提供任意文件或属性修改接口。
- Hook 同时检查主用户、明确的应用进程、机型、系统版本和挂载标记；共享进程与系统服务不适配。异常时撤销本轮 Hook 并恢复已修改标记。
- 相册专用逻辑只在相册开关启用时工作。同步登记修复是幂等操作，先检查用户已开启自动同步，不更改用户同步选择或照片数据库。
- 保存通过下一次 BOOT_COUNT 激活远程配置；进程与挂载切换仍要求手动重启。启动预检有次数上限，不引入持续轮询服务。
- 原生应用关闭只撤销适配。补装应用只对主用户执行保留数据的卸载 / install-existing，共享文件与其他用户安装状态保留。
- 重新安装后缺少 LSPosed 作用域会进入可见等待状态，经公开 requestScope 授权和再次校验后才提交成功；不使用框架内部数据库写入。
- 安装登记变更前保存事务，失败尝试恢复旧登记及远程配置；不调用 songyuan 的 UID、下载数据库或桌面迁移路径。
- 启动校验覆盖实际 APK / 原生库 / 权限挂载、QESDK 两文件哈希、组件登记、远程配置版本和当前 boot ID，避免使用旧启动成功状态。
- QESDK 恢复仅接受指定 ROM 和已知目标哈希，使用同版本官方文本字节及只读挂载；先校验全部输入，失败撤销本轮挂载。
- WebUI 复用同一开关模型，区分原生撤销与补装删除 / 保留；图标和状态不改变后端语义。真实图标仅接受 PNG data URI。
- 两机型使用独立锁文件和构建入口。复用已测试的归档安全解包与共享校验，避免复制校验实现；代码保持单一职责，没有增加通用脚本执行功能。
- CI Actions 固定提交、仓库权限只读；私钥来自加密 Secret，临时文件权限为 0600 并在 always 步骤清理。生产 APK 校验固定签名指纹，不自动生成无法覆盖安装的新密钥。
- 发布仅包含模块、配套 APK、哈希和来源记录；ROM 构建资源独立管理，诊断、账号资料、手机截图和签名密钥不提交。

验证通过不代表所有业务或系统日志零异常：实体 NFC / 支付 / 短信、全库原片下载、长期续航及本轮未连接的 songyuan 真机均有明确边界。
